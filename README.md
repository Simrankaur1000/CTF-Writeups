# CTF & Security Lab Writeups

A collection of notes from hands-on cybersecurity challenges and training labs. The goal is to document the investigation process, technical reasoning, and lessons learned.

## Topics

- Web application security
- Cross-Site Scripting (XSS)
- Local File Inclusion (LFI)
- JWT security
- File-upload vulnerabilities
- Insecure Direct Object References (IDOR)
- Prompt-injection testing
- Enumeration and exploitation fundamentals

## Writeup format

Where applicable, each writeup records:

1. Challenge objective and scope
2. Reconnaissance and enumeration
3. Vulnerability analysis
4. Exploitation steps in the authorized lab
5. Evidence and result
6. Remediation or defensive takeaway

## Responsible disclosure

These notes are for educational environments and authorized CTFs/labs. Do not use techniques against systems without explicit permission. Sensitive challenge flags or platform-specific answers are included only where challenge rules permit.
